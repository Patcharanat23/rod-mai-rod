## จุดที่คนส่วนใหญ่พลาด

1. **เวลาเพี้ยน 7 ชั่วโมง** `<input type="datetime-local">` ให้ค่าแบบไม่มี timezone เช่น `2026-09-28T08:00` ต้องถือว่าเป็นเวลาไทย เติม `+07:00` แล้วแปลงเป็น UTC ก่อนส่ง ถ้าส่งไปดิบๆ api-backend จะตอบ `VALIDATION_ERROR` (ตั้งใจไว้กันพลาดแบบนี้)
2. **ปุ่ม "ใช้ตำแหน่งปัจจุบัน" ใช้ไม่ได้ตอนสาธิต** browser ให้ตำแหน่งเฉพาะหน้าที่เปิดผ่าน `https` หรือ `localhost` ถ้าเปิดผ่าน IP อื่นจะโดนปฏิเสธเงียบๆ และผู้ใช้กดไม่อนุญาตได้ ทั้งสองกรณีต้องมีข้อความบอกและให้เลือกเองแทน
3. **กด Plan ซ้ำหลายครั้ง** แพลนใช้เวลาหลายวินาที ปิดปุ่มระหว่างรอและแสดงสถานะกำลังคำนวณ
4. **แสดงแค่เส้นทางแรก** ต้องวาดทุก `route_options` เส้นที่ `is_recommended` เด่นกว่า และให้ผู้ใช้เลือกดูเส้นอื่นได้ อย่าเดาว่าตัวแรกคือตัวที่ดีที่สุด
5. **popup สรุปใช้ค่าผิดเส้น** `duration_min`, `risk_score`, `risk_level` ระดับบนสุดของ `TripPlan` คือของเส้นที่แนะนำ ถ้าผู้ใช้กดเลือกเส้นอื่น ต้องเปลี่ยนตัวเลขตามเส้นนั้น
6. **แท็บขวาขาดต้นทาง/ปลายทาง** `waypoints` ในแผนมีทั้ง `ORIGIN`, `STOP`, `DESTINATION` แสดงครบทุกจุดตามลำดับ พร้อมเวลาไปถึงและอากาศ ณ ตอนนั้น
7. **แก้ทริปแล้วยังโชว์แผนเก่า** หลัง PATCH หรือหลังแชทแก้ทริป (`plan_status: "STALE"`) ต้องบอกผู้ใช้และให้แพลนใหม่
8. **หมุดเกิน 5 จุด** จำกัดตั้งแต่ฟอร์ม และถ้าให้ลากสลับลำดับหมุดได้ ลำดับที่ส่งไปต้องตรงกับที่เห็นบนจอ
9. **ไม่แสดง warning** เช่น `FORECAST_OUT_OF_RANGE` (ทริปไกลเกินพยากรณ์) ต้องบอกผู้ใช้ว่าอากาศยังไม่มีข้อมูล ไม่ใช่โชว์ช่องว่าง
10. **ไม่มีทริปแล้วหน้าว่าง** ต้องแสดงแผนที่ + อากาศแบบ area เหมือน Overview
