# /assistant (โมดูล 3)

**ผู้รับผิดชอบ**: TBD (คนเดียวกับ `/safety-map`)
**สเปก**: `docs/SPEC.md` หน้า 4 · **endpoint ที่ใช้**: `assistant/chat`
หน้านี้แค่แสดงแชท การตัดสินใจทั้งหมดอยู่ที่ assistant-agent (โมดูล 8)

## จุดที่คนส่วนใหญ่พลาด

1. **กด Enter แล้วส่งข้อความภาษาไทยไม่ครบ** ตอนพิมพ์ไทยบางคีย์บอร์ด Enter ใช้ยืนยันตัวอักษร ต้องเช็ค `event.nativeEvent.isComposing` ก่อนส่ง
2. **ส่งซ้ำ** ปิดปุ่มส่งระหว่างรอคำตอบ และแสดงว่ากำลังพิมพ์
3. **ไม่สนใจ `actions`** ถ้าคำตอบมี `TRIP_CREATED` / `TRIP_UPDATED` / `TRIP_DELETED` ต้องแสดงการ์ดสั้นๆ ว่าทริปไหนเปลี่ยน พร้อมปุ่มไปหน้า My Trip และข้อมูลทริปที่หน้าอื่นเก็บไว้ต้องโหลดใหม่
4. **แสดงข้อความจากระบบเป็น HTML ตรงๆ** ห้ามใช้ `dangerouslySetInnerHTML` กับคำตอบ ถ้าอยากจัดรูปแบบให้ใช้ตัวแปลง markdown ที่ปิด HTML
5. **ส่ง history ทั้งหมดทุกครั้ง** ส่งแค่ประมาณ 10 ข้อความล่าสุด
6. **`LLM_UNAVAILABLE` แล้วดูเหมือนพัง** แสดงข้อความว่าตอนนี้ตอบคำถามทั่วไปไม่ได้ แต่คำสั่งเลื่อนทริปยังใช้ได้ พร้อมปุ่มตัวอย่างคำสั่ง
7. **ไม่มีปุ่มคำถามตัวอย่าง** ใส่ 3-4 ปุ่ม เช่น "ช่วงนี้เที่ยวที่ไหนดี", "เลื่อน Trip 01 ไปพรุ่งนี้" ช่วยตอนสาธิตไม่ต้องพิมพ์สด
