## จุดที่คนส่วนใหญ่พลาด

1. **โหลดหมุดทั้งประเทศทุกครั้งที่เลื่อนแผนที่** ขอเฉพาะกรอบที่เห็นอยู่ (`min_lat`...`max_lng`) และรอให้ผู้ใช้หยุดเลื่อนก่อนค่อยขอ (debounce ประมาณ 400 ms)
2. **หมุดซ้อนกันจนกดไม่ได้** ตอนซูมออกให้รวมหมุดเป็นกลุ่ม (marker cluster)
3. **ไอคอนไม่ครบ** ต้องมีไอคอนของทุก `hazard_type` ใน CONTRACT (ฝน ฝนหนัก ลมแรง น้ำท่วม เสี่ยงดินถล่ม พายุ แผ่นดินไหว) และไอคอนสำรองถ้าเจอชนิดที่ไม่รู้จัก ห้ามพัง
4. **แสดงข้อมูลประเมินเหมือนประกาศทางการ** หมุดที่ `source: "DERIVED"` ต้องมีคำว่า "ประเมิน" ให้เห็นชัด
5. **ไม่บอกว่าข้อมูลเก่าแค่ไหน** แสดง `updated_at` ในรายละเอียดหมุดเสมอ
6. **สีไม่ตรงหน้าอื่น** ใช้ `RiskBadge` / สีจาก `shared/` ให้ HIGH สีเดียวกันทั้งเว็บ
