# /login และ /overview (โมดูล 1)

**สเปก**: `docs/SPEC.md` หน้า 1 · **endpoint ที่ใช้**: `auth/login`, `auth/register`, `me`, `trips/upcoming`, `trips/{id}`, `weather/area`
นอกจากสองหน้านี้ โมดูล 1 ดูแลโครงเว็บ (เมนู 4 แท็บ, layout) และของกลางใน `shared/` ตาม `apps/web/README.md`

## จุดที่คนส่วนใหญ่พลาด

1. **ทริปที่ "กำลังจะมาถึง" ผิดตัว** ใช้ `GET /trips/upcoming` อย่าเลือกเองจาก list (ทริปที่ออกไปแล้วต้องไม่ขึ้น)
2. **ทริปมีอยู่แต่ยังไม่เคยแพลน** `plan` เป็น `null` ต้องแสดงหมุดต้นทาง/ปลายทางพร้อมปุ่ม "ไปวางแผน" ไม่ใช่วาดเส้นทางที่ไม่มี
3. **แผนเก่า** `plan_status: "STALE"` ต้องบอกผู้ใช้ว่าข้อมูลอาจไม่ตรงและให้กดแพลนใหม่
4. **ไม่มีทริป** ต้องแสดงแผนที่ + อากาศแบบ area รอบตำแหน่งผู้ใช้ ถ้าผู้ใช้ไม่อนุญาตตำแหน่ง ใช้กรุงเทพเป็นจุดกลาง ห้ามค้างรอ
5. **token หมดอายุแล้วหน้าค้าง** ทุก 401 ต้องล้าง token แล้วพากลับหน้า login (ทำใน `shared/api.ts` ครั้งเดียว)
6. **เก็บ token ในที่ที่หายตอน refresh** ผู้ใช้กด F5 แล้วต้องยังอยู่ในระบบ
7. **ช็อตคัตไม่ครบ** Overview คือหน้ารวมทางลัด ต้องกดไปทั้ง 3 หน้าที่เหลือได้จากตรงนี้
