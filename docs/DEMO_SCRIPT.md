# DEMO_SCRIPT.md - สคริปต์ตอนสาธิต

เส้นสาธิตตาม `docs/PLAN.md`: login > สร้างทริป กรุงเทพ ผ่าน นครสวรรค์ ไป เชียงใหม่ > กด Plan > เห็นเส้นทางจริงพร้อมความเสี่ยงบนแผนที่ > แชท "เลื่อน Trip 01 ไปวันถัดไป" > หน้า My Trip เปลี่ยนตาม

เวลารวมประมาณ **7 นาที** (เส้นหลัก 6 นาที + เผื่อ 1 นาที) ถ้าต้องสั้นกว่านี้ ตัดช่วง 4 (Safety Map) ก่อน ห้ามตัดช่วง 2-3 และ 5-6 (RUNBOOK หัวข้อ E)

**คนพูด** (ร่าง ตกลงกันอีกครั้งก่อนซ้อม): **Jirapa** = คนคุมเครื่องช่วง My Trip (โมดูล 2) · **Suphakorn** = คนคุมเครื่องช่วง Safety Map + แชท (โมดูล 3) · คนเปิดและปิดการนำเสนอ ให้ทีมเลือก ช่องที่เขียนว่า "ผู้นำเสนอหลัก"
